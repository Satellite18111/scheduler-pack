## 二、源码层面

7 个 Java 文件与 `index.html` 全部通读，实现风格为自创，与 Scene 架构无交集：

- `NativeBridge.java` / `MonitorService.java` 用 `R:` `T:` `C:` `G:` `F:` `CT:` `BT:` `BS:` `P:` 标记 + `__NS_END__` 的自定 shell 协议；
- 自绘 `ToggleSwitch`、`roundBg()` / `circleBg()`；网页侧 `window.__ev` 桥 + `S` 状态对象、手写 CSS 变量主题、Canvas 曲线、`openSheet()` / `toast()`，无任何前端框架；
- 唯一的外部接口是数据：`/sdcard/Android/yc/uperf/cur_powermode.txt`、`perapp_powermode.txt` 与 sysfs 节点。这些属于 uperf 与内核，不是 vtools 的资产（vtools 仓库内检索 `uperf` / `powermode` / `perapp` 均为 0 命中）。

## 四、法律逻辑

GPL-3.0 §5 规范的是「code copying / work based on the Program」。以下情形均不落入：

- 功能思路、UI 布局、该读哪些 sysfs 节点 —— 事实与方法，非受版权保护的表达；
- 运行时读写他人定义的配置文件 —— 属互操作，不构成链接或衍生作品；
- 独立实现同样功能（即便文件格式相同）。

本项目也未分发 vtools 的任何代码或二进制。GPL 义务只在「分发」时触发，自用不触发。
